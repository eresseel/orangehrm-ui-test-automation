# Követelmények

- JDK 17 vagy újabb
- Maven 3.x **vagy** csak a projektben mellékelt `mvnw` / `mvnw.cmd` (Maven telepítés nélkül)
- Google Chrome (telepítve)
- Internetkapcsolat (a tesztek a publikus demo oldalt használják)
- Docker módú futtatáshoz: Docker (és opcionálisan Docker Compose) — ekkor JDK/Maven/Chrome
  lokális telepítése nem szükséges, ezeket a konténer image tartalmazza
